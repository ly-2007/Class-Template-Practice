## 项目名称
MyArray

* 一个教学用的 C++ 动态数组实现，模仿 `std::vector` 的核心机制，项目用于检验类模板学习成果及练习实战古法编程

## 功能
- 1. 构造（含有参与拷贝构造，避免浅拷贝）
- 2. 尾插法（类数组）
- 3. 尾删法（同样类数组）
- 4. 重载[] && = && 类的<< 
- 5. 实现对给定类型与自定义类型对象的存储与输出
- 6. 析构delete

## 练习知识点：
- 1. 类模板的分文件编写（.hpp）
- 2. 函数重载（[]/=/<<）
- 3. 友元函数
- 4. 类模板/函数模板
